# ONE PAGE — compact screens, a pop-up page on every press; choices are one ordered grid (2026-10-31)

Owner rows 246, 247 and 248 (quotes verbatim; renumbered from 242/243/245 because the city slice
already holds those row numbers), branch `one-page`, **client-only** (no migration, no server
change, no text meaning changed). PR open.

## The law

- **The document never scrolls** — `documentElement.scrollHeight ≤ clientHeight + 1`, same for width.
- **The tab's own Sheet never scrolls** — `Sheet` carries `data-sheet`; scrollHeight = clientHeight,
  scrollTop 0, on every route and every face (Map and the City page are one glass and draw none).
- **Every block is ONE compact summary row; a press opens a full-screen page.** `SummaryRow` carries
  the title, its key figure and the word Open. `DetailPage` is a fixed overlay with a back press and
  its own bounded scroll (`ScrollPane`). The page root itself does not scroll; the tab behind is
  untouched (out of flow), so the press law holds. Nothing is unfolded in place and nothing deleted.
- **Every set of tappable choices is an ordered grid** (`TileGrid`/`TileChoice`): equal cells, fixed
  columns, 44 px, stable order.

`tests/onepage.spec.ts` walks all ten routes, the four desk faces, the five Stats faces **and every
summary page** (opening each as a player does) at 390×844 and 1280×800.

## Decision: an OVERLAY page, not a route

*"make everything small, compact and once clicked show new page popping up"* — the mechanism is ONE
`DetailPage` overlay, chosen by default over `/stats/markets`-style routes because:

1. **The press law.** A route remounts the tab and rebuilds the compact screen behind the press. The
   owner's law says a press selects and opens; nothing behind it moves or rebuilds. A fixed overlay
   leaves the tab exactly as it was; the back press reveals it untouched.
2. **State.** Which city is in hand, which face is selected, a loaded live figure — a route loses
   all of it; the overlay keeps it.
3. **One implementation.** Every screen uses the same primitive (back press, title, figure, bounded
   scroll); no screen invents its own page and no router table grows per block.

## What moved (nothing removed)

Command Trade/Cargo/Orders/Map; every Stats block (World money, Money log, New money, the economy
watch, money flows, Markets filters/movers/goods, Cities filters/list, Merchants charts/best/worst/
all, best sales, leaderboard); the Codex catalogue; the Ledger feed; Rank's board; Routes' lanes;
each Profit day. Each page holds the whole former block. `SectionFold` and `ChipRow` are deleted.
The tile grids stay. The City page is untouched (`src/features/city/**`) and asserted only.
