## What lights it

**`economy_closed`**, the closed-economy switch (0228; E7's `economy_close_switch`). Every new path asks
`public.economy_closed()`, so E4b goes live WITH the switch, as the owner wants. Its knobs can each turn one part off while
lit: `port_fee_base` and `port_fee_pct` at 0 → no fee; `port_prep_seconds` 0 → no port time; `country_tax_factor` all 1 →
no country scaling. Dark, no knob is read on a path that changes an answer.

## 0236 — the gift reads her cash

Decided by default (the owner may reverse): a merchant company is BROKE when her **purse** is under `merchant_broke_pct`
(0.2) × her capital, not her worth (purse + cargo at cost). One hunk in `public.capital_gift_pass` drops the worth test.
Worth still orders the pass and stays in the event. It is the same figure Stats' "Broke merchants" line counts (0229).
Prod now: 45 houses broke by purse, Σ capital 276,000 (check 6). 0234's worth test found 0 at head 0231.

## 0237 — every port charges and takes a minute

| piece | what |
|---|---|
| Relations | **No new table.** `public.power_relations` exists since 0196 (from `data/relations.json`), with one reader, `public.power_stance(a, b)`. A second table would be a second authority. §4c's four words map onto its five stances: same = `home`, friendly = `ally`, neutral = `peace`, rival = `rival` and `war`. Seed table below. |
| Home country | **No new column.** `players.nation_id` is it. For every player it equals the founding port's power (prod: 19 of 19, check 5). A merchant's nation is her capital's by definition (`nations.capital_port_code`), the country E4's gifts read. |
| Knobs | `port_fee_base` 50, `port_fee_pct` 0.005, `port_prep_seconds` 60, `country_tax_factor` `{home 0.25, ally 0.5, peace 1, rival 2, war 2}` |
| `public.country_factor(stance)` | THE factor. 1 while open; closed, the knob's entry (an unpriced stance raises). |
| `public.port_fee(port, player, value)` | THE dock fee: `round((50 + 0.5 % × cargo at cost) × factor)`. 0 while open, with the purses dark, or where there is no purse. Cargo is valued at what it cost (`fleet_stock_at_cost`), so no quote is asked on the arrivals path. |
| `public.port_call(...)` | Called from `voyage.settle`'s arrival, lit only. Pays the fee from her purse to the city (`pay_city`, kind `PORT_FEE`). What the purse can't cover is owed (`port_fee_debts`), and she still docks. Sets `fleets.ready_at` = arrival instant + 60 s, only when that is still ahead (a voyage settled late is ready at once). |
| `public.port_fee_collect(...)` | In `cmd.do_sell`, after tax and wages: what she owes this harbour, up to the sale's net, goes to the city. |
| `public.port_time_wake(...)` | In `tick_arrivals` (every 15 s): a fleet whose port time is up runs her queue (`cmd.advance`), so the SAIL that waited leaves. `ready_at` is cleared first, so each fleet is woken once. |
| Prep gate | `voyage.sail_refusal` answers `E_PREPARING` ("she is making ready in port — 42 s to go"; figures = seconds gone / seconds asked). `cmd.advance`: a SAIL **waits** in the queue while `ready_at > now` (nothing is refused, nothing skipped). `cmd.preview`: a SAIL is judged as it will run when she is ready (the port time is set aside inside the preview's rolled-back block), so the send tray can queue it. Merchants obey the same rule: their route SAILs go through `cmd.advance` too. |
| Tax by country | `world.tax_rate`, closed: `least(base × country_factor, greatest(base, tariff_rate_max))`. It replaces 0147's citizen cut and 0196's tariff where 0196's tariff applies (a company, the race on). The cap is 0196's: at most 0.35, unless the city's own rate is higher. |
| Reads (lit only, absent dark) | `world.fleets`: `ready_at` while in port time. `world.town_hall`: `dues` (stance, factor, the fee at the base). `world.good_board` sell rows: `dues` (the fee for this parcel there). |
| Stats | `PORT_FEE` → moved ("Dock fees"). A fee is a ledger row (−) and a city flow (+), so it nets to 0 new money. |

Decided by default:
- The fee and the port time apply only at a HARBOUR with a purse (a sea place or open anchor has none).
- War = 2×, the same as rival.
- The fee counts cargo at cost.
- The board's `profit` does not subtract the dock fee; it is shown on its own line.
- The country factor rides the race (`influence_on`), as 0196's tariff does. The race is on on prod.

## The arrivals job cost (asked: under 5 %)

Measured on the cached world (850 fleets, 837 merchants; prod has 856), PGlite, with the ~21 arrivals a run prod sees
(check 7: 5,014 arrivals in the last hour = 20.9 per 15-s run), against prod's ~7 s a run:

- **Lit: + 32.4 ms a run (1.54 ms per port call) = 0.46 %** of the job.
- **Dark: + 6.7 ms a run = 0.10 %**: the `economy_closed()` test at each arrival (0.29 ms each through the node driver)
  and the wake's scan of the partial index (0.66 ms with nothing due).
- Lit, the wake also runs the waiting SAILs. That is not new work: the same SAIL ran at arrival before. It now runs about
  a minute later.

PGlite through the node driver is slower per call than prod, so these are upper figures. The script was scratch and is
not committed.
