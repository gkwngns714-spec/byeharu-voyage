## 1. The laws (each one is MEASURABLE — it becomes a spec line, not a taste)
- **U1 UNFOLDED.** A face shows every key figure and its small chart IN PLACE. A press that opens a page is for an UNBOUNDED list (the
  629 goods, the ledger, a month of rows) or a long explanation — never to reveal one figure, one sparkline or a four-row table. A summary
  row whose page holds fewer lines than the row's own height is a defect: inline it. (This reverses the one-page slice's "every summary
  opens its own page" wherever it hides a single figure; where a page is right it stays, with a way back.)
- **U2 NO PAGE SCROLL** at 390×844 and 320×640 on every tab and face. A long list scrolls INSIDE its own panel (header, frame, tiles
  stay put; the cut edge is visible), never the page. Desktop (1280×800) is the same layout with more room: larger charts, more rows —
  NEVER a different information architecture, and never a mostly empty page.
- **U3 COMPACT, FULL.** Label→figure hug (8–12 px, the shared `Row`), tabular numerals, no dead horizontal space, a 44 px floor only on
  PRESSABLE rows. Nothing is removed to buy space: every figure the old face had is still there (move, pack, inline, shrink the chart).
- **U4 ONE HOME PER FACT** (already law). **U5 NO OVERLAP, NO ONE-CHARACTER WRAP, NO CUT TEXT** without press-to-read (the 2026-11-01
  phone Market face broke all three). **U6 MOBILE FIRST:** design at 390 first, then widen. **U7 WORDS** 1–2 plain words, EN + KO through
  `src/lib/i18n/dict/*`. **U8 A press selects:** it never re-flows the frame (dont-restructure-on-press).
