## The aboard clock

0127: a voyage teaches only the captains aboard when it departed (`officer_xp.aboard_since`, else
`hired_at`). Since 0157 a captain is seated, moved or hired into a fleet only while it is docked
(D9: `seat_captain_for` checks both ships, `sign_officer` refuses a fleet at sea), and no function
moves a ship between fleets (`update public.ships … fleet_id` appears only as a filter in
`do_repair`, `fleet_load`, `settle`). So whoever sits in a fleet at sea sat there before she sailed,
and the clock added nothing. `captain_xp_credit` keeps "signed by then" (`hired_at <= p_since`);
`captain_seat_put` loses `p_came_aboard` (drop + create at three arguments, ACL asserted equal). The
migration asserts old filter = new for every captain seated in a sailing fleet.
