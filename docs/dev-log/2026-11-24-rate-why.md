## Server (0493; no switch, no coin, nothing written)

- `public.company_rate_line(kind) -> (line, one_time)`: the one map of a ledger kind to a plain line. IMMUTABLE.
- `public.company_rate_for(player)`: the one rate authority. The same rows, window and rounding as 0480's rate. It answers
  `{per_hour, net_24h, one_time_24h, all_24h, since, top, lines[{line, total_24h, per_hour, count, one_time}]}`.
  - `per_hour` and `net_24h` are the RUNNING lines only. This deliberately replaces 0480's rule for the one-time kinds.
  - `all_24h` is every line: 0480's old `net_24h`, to the unit. The running lines sum to `net_24h`, all lines to `all_24h`.
  - `top`: the lines the headline names, chosen by the server: under zero her two largest losses, else her two largest gains.
  - `lines`: running first, then one time; in each the largest loss first.
- `world.company_rate()`: the caller's own. Server only for now (no screen asks it alone).
- `public.hq_board_for`'s `rate` re-pointed by one hunk; `per_hour`, `net_24h`, `since` stay, the rest arrive with the board.
