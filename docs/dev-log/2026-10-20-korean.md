### The chosen approach (decided by default; the owner may reverse any of it)
1. **No library.** A typed dictionary module, ~150 lines of machinery. `react-i18next`/`i18next`
   would add 50 KB and a second place to decide plurals and interpolation; the game needs ~1,500
   keys, string interpolation, a one/other plural and a locale tag. If a library is ever added,
   pin an exact version (owner rule).
2. **Home: `src/lib/i18n/`** (machinery, entrance `index.ts`). It must sit under `lib/format`,
   because `formatTons`/`formatVoyageDays`/`formatMiles`/`formatKnots`/`formatUnitPrice`/
   `formatUnits` spell English unit words and `src/lib/*` may import nothing above it
   (`tests/sections.spec.ts` "machinery knows nothing above it"). `lib → lib` is allowed;
   `components/ui`, `domain`, `chart`, `live`, `features`, `app` all may import it.
3. **Shape of the dictionary.** One file per screen/domain in `src/lib/i18n/dict/` so parallel
   agents never edit one file: `shellDict`, `authDict`, `foundDict`, `mapDict`, `commandDict`,
   `fleetsDict`, `routesDict`, `ledgerDict`, `rankDict`, `profileDict`, `codexDict`, `galleryDict`,
   `liveDict` (the `src/live` faces), `formatDict` (units), `domainDict` (`domain/order/text.ts`,
   `domain/fleet` where-lines), `codesDict` (E_ codes), and the proper-noun maps. Each file:
   ```ts
   export const authDict = defineDict({
     en: { title: 'Start your company', … },
     ko: { title: '회사 설립', … },
   })
   ```
   `defineDict<E>(d: { en: E; ko: { [K in keyof E]: Msg } })` — a **missing or extra Korean key
   fails `tsc`** (mapped type + excess-property check). `Msg = string | { one: string; other: string }`.
   Export names are unique and suffixed `Dict` because `tests/duplication.spec.ts` refuses two
   modules exporting one name.
4. **Key type.** `type Key = { [S in keyof DICT]: \`${S}.${keyof DICT[S]['en']}\` }[keyof DICT]`
   — `t('auth.title')` is typed; a typo fails `tsc`. Interpolation `{name}` placeholders;
   `t(key, { n: 3 })` picks `one`/`other` on `n`.
5. **Reading strings.** `useT()` hook (`useSyncExternalStore` on a tiny locale store) returns a
   per-locale `t`, so `useMemo` deps on `t` invalidate on switch. Pure code (`lib/format`,
   `domain/*`) reads `t` from the module directly. `AppShell` subscribes to the locale, so the
   whole tree re-renders **in place** on a switch (no remount, no reload). The four `memo(`
   components are all in `src/chart` (ChartCanvas, CoastlineLayer, PortsLayer, SeaLayer); check
   whether any renders text — the labels layer prints port names, which go through the proper-noun
   map, so those must call `useT()`/`useLocale()` themselves.
6. **Locale state.** `'en' | 'ko'`. Default: `navigator.language` starts with `ko` → `ko`, else
   `en`. Remembered per viewer in `localStorage` under one key, every read/write in try/catch.
   Playwright's default locale is `en-US`, so **every existing spec keeps running in English**
   unchanged; the Korean spec sets `test.use({ locale: 'ko-KR' })`.
7. **The switch.** A `Segmented` (`components/ui/Chip.tsx`) 한국어 / English on
   `features/profile/ProfileScreen.tsx` and on `features/auth/AuthPage.tsx` + `features/found/
   SignTheBook.tsx`, so a new player picks before reading anything.
8. **Numbers and dates.** `lib/format/numbers.ts` keeps its fixed comma grouping (Korean groups by
   three with a comma too, and the file's header forbids an Intl-derived separator so shared
   leaderboard figures never differ by viewer). Unit words move into `formatDict`. Dates: ONE
   helper in `lib/format/time.ts` over `Intl.DateTimeFormat(localeTag())` (`ko-KR` / `en`) replaces
   the three `toLocale*('en', …)` calls above; the bare `toLocaleString()`s become `formatInt`.
9. **Server text.** A refusal is `{ code, sentence, fixes, figures? }` (`src/lib/rpc/result.ts`).
   `Note` (`components/ui/Note.tsx`) already receives `code`; in `ko` it prints `codesDict[code]`
   (with `figures.have/need/unit` interpolated where served) and **falls back to the English
   sentence when no Korean entry exists**. Free-text server sentences without a code (the
   captain's trait lines, `Not in use yet.`, the estimate sentence, History lines from
   `world.ledger`) stay English in v1 and are listed in the PR. Codes the client already branches
   on (`E_NOT_DOCKED`, `E_HOLD_FULL`, `E_BUSY`, `E_UNAVAILABLE`, `E_NO_STOCK`, `E_NO_CARGO`,
   `E_NEEDS_SKILL`, `E_CREW_MAX`, `E_CONTRACT_SHORT`, `E_HAGGLE_SPENT`, `E_TOW_FUNDS`,
   `E_NOT_WRECKED`, `E_NOT_IN_PORT`, `E_NO_YARD`, `E_WRONG_YARD`, `E_NO_SUCH_PORT`,
   `E_NOT_YOURS`, `E_NOT_SAILING`, `E_SAME_DEST`, `E_MINOR_POWER`, `E_ALREADY_FOUNDED`,
   `E_CONTRACT_EXPIRED`, `E_DAILY_CAP`, `E_PAUSED`, `E_STALE`, `E_REFUSED`, `E_SERVER`,
   `E_TRANSPORT`, `E_FORBIDDEN`, `E_NO_SUCH_RPC`, `E_CONSTRAINT`) are the first list for
   `codesDict`; the full set is in `supabase/migrations` (`cmd.refuse`).
10. **Proper nouns — one data map each**, keyed by the served **code** (`SnapshotPort.code`,
    `SnapshotGood.code`, `SnapshotNation.code`, `SnapshotShipClass.code`), read where the client
    already resolves names: `portNameOf` / `nationNameOf` (`src/live/worldStore.ts:358,375`) and
    `categoryLabel` (`src/components/ui/goodIcons.ts:168`). Sources: `data/ports.json` (238
    ports, `name`/`localName`/`countryName`), `data/goods.json` (555 goods, 17 categories),
    `data/regions.json` (25), `data/ship-lines.json` (11 lines), ship classes from the served
    snapshot. Rule: an established Korean name where one exists (리스본, 세비야, 런던,
    암스테르담, 이스탄불, 부산; 후추, 정향, 비단, 도자기), the original otherwise; **a city or good
    with no entry prints its served name** (a truthful lesser answer, NO_SPAGHETTI §7C). Officer
    and person names unchanged. Fleet names are the player's and unchanged.
11. **Specs.** (a) `tests/i18n.keys.spec.ts` — pure: every dict's `en` and `ko` key sets are equal
    and no `ko` value is empty or equal to its `en` value unless allow-listed (proper nouns,
    `🪙`, codes). (b) `tests/i18n.ko.spec.ts` — browser, `locale: 'ko-KR'`: renders the main
    screens (auth, found, map, command faces, fleets, routes, history, rank, profile, codex) and
    asserts no visible text node matches `/[A-Za-z]{3,}/` outside an allow-list (proper nouns,
    captain names, fleet names, `S/A/B/C` grades, units served by the server). Existing specs
    select by English text and must keep passing untouched.
12. **Korean layout.** `word-break: keep-all` on `body` in `src/index.css` (one rule, not per
    screen) so Korean wraps by word; check every label at 390 px (Nav tabs, the desk's five faces
    `Markets · Plans · City · Invest · Profit` → `시세 · 계획 · 도시 · 투자 · 수익`, Chip rows, the
    fleet strip).
