# 2026-10-18 — every nation flies a real flag — `osn-flags`

**The owner, verbatim:** *"flag images for each city, i am sure there are some that aren't licensed
meaning it could be used in our game. find country flags, apply to our game to make the game more
visual. like beside the name show flag that are influenced by, when pressing a ship or city, also
show flag"* (OWNER_REQUESTS row 140).

Client only. No migration: every payload that names a nation already serves its code
(`world.allegiance` → `portNationOf`, `company.nation_code`, `line_nation`, `player.nation`).

## The flags (public/flags, 23 files, 53.3 KB)

Prod was read first (`supabase db query --linked`, read-only): `public.nations` holds 23 codes —
AYU BAN DNK ENG ESP FRA GEN GUJ HAN JOS JPN MAR MLB MNG MUG NLD OTT PER POL PRT RUS SWE VEN — the
same 23 the migrations seed (0003 + 0130).

Each candidate was looked up through the Commons API (`prop=imageinfo|revisions`), and taken only
when its licence is Public Domain or CC0. **15 are from Commons** (ENG, DNK, SWE, JPN from PD-shape /
national PD; ESP, NLD, GEN, MAR, POL from PD-self; FRA PD-user; PER PD-user-w; RUS PD-RU-exempt;
HAN PD-Flag-Germany; JOS PD-old/PD-South Korea; BAN CC0). **8 are original drawings**:
- MUG — both Commons Mughal standards are CC BY-SA → a golden sun on green;
- OTT — the only PD "1517-1793" file is filed under *Fictional flags of historical entities* → a white crescent on red;
- GUJ — the CC0 file is filed under *Fictional SVG flags of India* → a golden rosette on green;
- MNG — the only PD file is titled *(fictitious)* → a sun-and-moon banner (日 + 月 = 明) on red;
- AYU — the PD Commons flag is Siam's 1855 elephant → the plain red ensign attested c. 1680;
- MLB — nothing on Commons for the Zamorin → a golden eight-pointed star on red;
- PRT, VEN — the PD Commons files are 335 KB and 787 KB (213 KB after svgo) → simplified after those designs (the crowned royal shield on white; the six-tailed gonfalon with St Mark's halo and book).

Every sourced file was downloaded into an empty scratch directory, read, and run through
`svgo` 3.3.2 (`convertStyleToAttrs`, `preset-default`, `removeScriptElement`, `removeDimensions`,
`removeXlink`), then scanned for `<script>`, `<style>`, `<image>`, `<foreignObject>`, `on*=` and any
outside `href` / `url()` — none. JOS.svg came back with `svg:`-prefixed markup and no viewBox, which
`tests/flags.spec.ts` caught (it would not have scaled into the box); it was rewritten to the
default namespace with a viewBox. The licence table, the rejected files and the licence lines of
each page are in `public/flags/SOURCES.md`.

## Where they are drawn — one component

`src/components/ui/Flag.tsx` (+ `flagSrc.ts`): code + name → the bundled `<img>`, `alt` and `title`
the nation's name, a 3:2 box in three sizes (`caption` 12, `body` 14, `title` 18 px), the flag fitted
uncut, a hairline drop-shadow so a white flag has an edge. Pure; two live wrappers decide WHICH
nation:
- `HullCountry` (was a unicode glyph; now `Flag`) — a hull's line, a merchant's company, your
  company (Profile), the Town Hall's holder and standings, the Countries board, the picker;
- `PortFlag` (new) — a city's holder, through `portNationOf`, nothing until it is read.

Shown: the city tray's name (`SendFleet`), the Port tab's title, your fleet's tray (your company's
flag beside her name; the flag of her port and of her destination), a ship's panel (yours now too —
`VoyageTray` passes the house's nation), a merchant's sheet and rows, the Codex's nations. The
city tray's line now reads `Portugal · Home city` in words (`CityFlag`), the flag having moved
beside the name — one flag per city in the tray, not two. No `flag_char` is read by any screen any
more (`tests/map.flag.spec.ts` greps).

**The chart's names.** `usePortFlags` now hands the holder's nation CODE; `labels.ts` carries it on
the request (`flag`), widens the planned box by `FLAG_ADVANCE_EM` so the collision rule keeps the
flag clear, and `LabelsLayer.tsx` draws the same file as an SVG `<image>` at the box's left edge.
`ChartCanvas.tsx` / `CoastlineLayer.tsx` untouched (another agent is on the blinking there).
Decided by screenshot: drawn whether Regions is on or off (D14 had it Regions-only; the owner's
sentence overrides), but only once the chart is close enough to name quiet harbours — at the world
view the names stay bare.

A defect found on the way: an `<image>` sized in the chart's units (a name is ~0.15 units tall)
loaded, laid out at 17×11 px, and painted NOTHING in Chrome. It is now drawn in a 30×20 box and
scaled down by a transform.
