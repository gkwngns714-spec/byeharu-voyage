## 1. The server read — `world.report(p_span)`

- `p_span` is `'day' | 'week' | 'all'`, in GAME DAYS on the one clock `world.game_day`:
  **day** = today; **week** = the last seven game days (today−6 … today); **all** = every row.
  The client never computes a span or a day.
- It is DERIVED from the append-only `public.ledger` per read and stores nothing. `FOUNDING` is a
  company's capital and is left out; `PROBE_%` kinds are never served.
- **Sections** exactly §4's table, fixed and always all eight: Trade, Crew, Supplies, Repairs,
  Insurance, Invest, Ships, Other. Any kind not listed stands in Other **under its own name**
  (the server sends `word` = initcap fallback), so nothing is dropped.
- **Points** form a PARTITION: a **port** when the row names one (0284 fills it from the fleet's own
  dock); else a **voyage** (the from/to codes and the departure game day); else **Earlier**, always
  last. A row naming both a port and a voyage counts once, under the port. The place sums therefore
  equal the section sums, and the day/week/all axes are zero-filled 1 / 7 / every day since the
  earliest row.
- **PORT_FEE, found on prod, and the design's stale sentence.** §4 said "port fees are not a ledger
  kind"; the read-only prod check found a real `PORT_FEE` kind — **35,870 rows**, since 2026-10-26
  (0215's city-visit fee). The brief's rule wins: **port fees stay INSIDE Trade**. 0286 maps
  `PORT_FEE` into the Trade section — never a section or a place of its own; its line keeps the kind
  so nothing is dropped and Trade stays the sum of its lines. Both the self-assert and PROOF 13
  plant a fee and assert it inside Trade.
- **`world.books` (0177) is RETIRED as a client door.** 0286 removes its registry row and revokes
  the `authenticated` grant. Its body stays: frozen **0232**'s self-assert calls `world.books(7)` as
  the migration OWNER during a from-zero apply (0232:1236). Dropping the function would make the
  chain un-appliable from zero, and an applied file is history. No live runtime caller remains: the
  desk's Profit face is replaced, and Stats › Me now reads `world.report('week')`.
- One new function, `world.report(text)`, STABLE / SECURITY DEFINER / search_path `public, pg_temp`,
  authenticated only, registered in `public.client_rpc_entry_points()` at the same count (books out,
  report in). Every other function in public/cmd/world/voyage is unmoved by md5.
