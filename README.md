# byeharu-voyage

A text-and-tabs age-of-sail trade & exploration strategy game, built on the byeharu core
(React 19 + Vite + TypeScript + Tailwind 4 + Zustand + Supabase, server-authoritative RPCs).

Working title. Successor to `byeharu` — the space game's combat layer is retired; this is a new
game that keeps the proven core (auth, shell, migration chain discipline, CI apply-proof).

- **Commands** are issued on a command tab, in words — not by clicking a battlefield.
- **The map is a view, not a controller.** It shows where your fleets are and where they are going.
- **The world is the real world:** real countries, real port cities, real coordinates.

See `docs/DESIGN.md` for the game design and `docs/DEV_LOG.md` for the running record.
